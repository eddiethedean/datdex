# Datdex Roadmap

## Phase 0 — Contract freeze
Asset identity, qualified names, schema normalization/fingerprints, lineage contracts, publisher events, authorization hooks, and DB model.

## Phase 1 — MVP
Datasets/data products, schemas/fields, locations, ownership/tags/classifications, lineage, freshness/quality observations, search, REST API, SQLite/PostgreSQL.

## Phase 2 — Ecosystem adapters
ShuETL publishing, ETLantic lineage/schema publishing, AuthMate authorization, and Hedron catalog UI.

## Phase 3 — Discovery
PostgreSQL search, faceting, saved searches, relevance explanation, optional external search providers.

## Phase 4 — Connectors
Optional discovery for databases, warehouses, object stores, Parquet/Arrow, and selected APIs.

## Phase 5 — Governance
Classification vocabularies, stewardship, lifecycle, documentation workflows, audit export, workspace boundaries.

## Phase 6 — Interoperability
OpenLineage ingestion/export and selected metadata standards.

## Phase 7 — Advanced intelligence
Optional semantic discovery, lineage impact analysis, schema-change impact, dataset health aggregation, and metadata recommendations.

Datdex should remain lightweight even as optional integrations grow.
